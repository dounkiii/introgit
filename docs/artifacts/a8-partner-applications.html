換金経路を5枠うめる

パイプラインは AFF_* という5つの空きスロットを持っています。 A8 で提携が承認されるとそこに広告リンクが入り、記事とショート動画に CTA が自動で差し込まれます。 申請は5件まとめて出してください。順位は「承認後にどれを優先して使うか」の話です。

画面の文言は保証できません。 この環境から a8.net に接続できないため、 実際のメニュー名を確認できていません。下の手順は意味で合わせてください （「プログラム検索」が別の名前なら、広告主を探す画面を開く、と読んでください）。 違っていたらスクショを送ってもらえれば直します。

PATH 申請までの流れ

  1. A8 にログインする（アカウントはすでにあり、note のサイト登録も完了済み）
  2. プログラム検索（広告主を探す画面）を開く
  3. 下のキーワードで検索する。タップでコピーできます
  4. 結果から広告主を選び、提携条件と禁止事項を読む。お金・税金ジャンルは表現の制限が入ることがあります
  5. 提携申請するを押す。「即時提携」ならその場で承認、「審査あり」なら数日〜1週間待ちます
  6. 5枠ぶん繰り返す。待ち時間が重ならないよう、承認を待たずに次を出してください

NEXT 承認されたら

広告主の管理画面で広告リンクのURLをコピーして、GitHub に登録します。
リポジトリ → Settings → Secrets and variables → Actions タブ → New repository secret
Name には上のスロット名をそのまま入れます（例 AFF_ACCOUNTING_SOFT）。 Secret に登録すれば値は暗号化され、このリポジトリが public でも中身は見えません。
Dependabot タブではありません。 同じ画面に Actions / Codespaces / Dependabot の3つのタブがあります。 ワークフローが読むのは Actions だけです。別のタブに入れると、 登録済みに見えるのに実行時は空になります。
ログインIDとパスワードは誰にも渡さないでください。 必要なのは広告リンクのURLだけです。A8 は成果報酬の振込先口座に紐づくので、 漏れると金銭被害に直結します。
進捗はこの端末のブラウザにだけ保存されます（他の人には見えません）。
スロット定義の出典: config.yaml の monetization.offers
